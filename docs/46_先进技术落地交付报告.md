## 五、执行中发现的 4 个真实缺陷

1. **`pulsar-client` 缺失 → 事件层静默降级 Redis**（严重）
   消费者跑旧镜像 0.7.4 自带 pulsar；新镜像纯净构建没有 → `/events/stats`
   报 `transport=redis` 且 `last_error=null`，与"Pulsar 已打通"结论矛盾。
   **修**：补依赖 + `transport_degraded` 显式标记 + 2 项回归测试。

2. **世界模型 SQL 漏传 asset_id**（严重）
   3 个 `%s` 只传 1 个参数；mock 测试发现不了，线上 500。
   **修**：补参数 + 新增**真实 SQLite 集成测试**（不 mock）。

3. **测试间 DB 后端污染**（工程）
   sqlite 测试删 `sys.modules` → server 测试 11 项 422。
   **修**：只 reload `app.repository`；两种执行顺序均 78/78。

4. **SQLite UPSERT 主键未登记**（工程）
   新增 upsert 表触发翻译层守卫（按设计报错）。
   **修**：登记 agent_session / model_version 主键。
