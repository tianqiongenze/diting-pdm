# 02 · 软件需求规格说明书（SRS）

| 项 | 内容 |
|---|---|
| 文档编号 | DT-PdM-02 |
| 依据 | GB/T 8567-2006（章节结构）；ISO/IEC/IEEE 29148:2018（质量属性）；EARS 句式 |
| 版本 | v0.1 |
| 需求总数 | 功能 34 条 / 非功能 18 条 / 约束 9 条 |

> **EARS 句式约定**（本项目强制）：
> - `[Ubiquitous]` 系统应…（无条件）
> - `[Event]` 当 <触发> 时，系统应…（事件驱动）
> - `[State]` 当 <状态> 时，系统应…（状态驱动）
> - `[Option]` 若 <特性开启>，系统应…（可选特性）
> - `[Unwanted]` 若 <异常>，系统应…（异常处理）
>
> 每条需求必须：**可测试、有唯一 ID、有验收方式、有优先级（MoSCoW）**。

## 1. 引言

### 1.1 目的
定义谛听平台的功能与非功能需求，作为设计、开发、测试、验收的唯一依据。

### 1.2 范围
单厂区关键旋转设备的预测性维护智能体平台，覆盖数据接入、诊断、交互、决策、边缘五层。

### 1.3 术语
见 `docs/00 §9`。

### 1.4 参考
- GB/T 8567-2006 计算机软件文档编制规范
- GB/T 19873.1-2005 机器状态监测与诊断 振动状态监测 第1部分：总则
- GB/T 19873.3-2019 振动诊断指南
- ISO 13374-1/-2 机器状态监测与诊断 数据处理、通信与表示
- ISO 20816-1/-3 机械振动 振动烈度评价
- GB/T 22239-2019 网络安全等级保护基本要求
- GB/T 45654-2025 生成式人工智能服务安全基本要求

## 2. 总体描述

### 2.1 产品视角

```
              ┌──────────────┐
   运维人员 → │ 对话/报告界面 │ ← 设备科长/维修班长
              └──────┬───────┘
                     │ MCP / REST
              ┌──────▼───────────────────────┐
              │  Agent Harness 运行时         │
              │  （工具/权限/记忆/审计/评测）  │
              └──────┬───────────────────────┘
     ┌───────────────┼───────────────┬──────────────┐
     ▼               ▼               ▼              ▼
 诊断引擎        决策会诊        知识库        外部系统
 (SD/HA/PA)     (4角色+评估)   (故障模式)    (EAM/MES/备件)
     ▲
     │
 数据底座（DA/DM）：统一命名空间 + 时序库 + 事件
     ▲
     │ OPC UA / Modbus / MQTT / S7
  设备 / 传感器 / PLC
```

### 2.2 用户类别

| 角色 | 使用频率 | 核心诉求 | 关键功能 |
|---|---|---|---|
| 设备工程师 | 每日 | 快速定位异常 | 自然语言诊断、频谱查看 |
| 维修班长 | 每日 | 知道该干什么 | 方案卡、工单草稿 |
| 设备科长 | 每周 | 全局健康与风险 | 健康看板、周报 |
| 可靠性工程师 | 每周 | 故障模式与根因 | 案例库、RUL 曲线 |
| 生产计划员 | 按需 | 停机窗口协商 | 排产冲突分析 |
| 系统管理员 | 持续 | 稳定与合规 | 审计、权限、配置 |
| 算法工程师 | 持续 | 模型迭代 | 数据集、评测、A/B |

### 2.3 运行环境

| 项 | 要求 |
|---|---|
| 边缘节点 | 工业计算机，≥ 8 核 / 32 GB / 512 GB SSD，可选 GPU（≥ 8 GB 显存） |
| 中心侧 | 私有云 K8s，≥ 3 节点 |
| 网络 | 厂区工业环网 + 单向隔离闸（OT→IT） |
| 断网 | 边缘可离线运行 ≥ 72 小时 |

### 2.4 设计与实现约束（CON）

| ID | 约束 |
|---|---|
| CON-01 | 系统**不得**向 PLC/DCS 下发任何控制指令（只读采集） |
| CON-02 | 原始波形数据不得出厂区，出厂仅限特征值与事件 |
| CON-03 | 所有写操作（工单/备件）必须人工确认并留痕 |
| CON-04 | 必须支持国产化环境（麒麟/统信 OS、达梦/人大金仓可选） |
| CON-05 | 模型与算法必须可替换（插件化接口） |
| CON-06 | 必须满足等保三级技术要求 |
| CON-07 | 单节点采集能力 ≥ 5,000 点/秒 |
| CON-08 | 时间戳统一为 UTC，展示层转本地时区 |
| CON-09 | 禁止使用非商用许可的模型权重用于生产 |

## 3. 功能需求

### 3.1 模块 M1：数据接入与治理（DA/DM）

| ID | 类型 | 需求 | 优先级 | 验收方式 |
|---|---|---|---|---|
| FR-101 | Ubiquitous | 系统应支持 OPC UA、Modbus TCP/RTU、MQTT、Siemens S7 四类协议的接入，新增一种协议适配不得修改上层代码。 | Must | 接入 4 类设备演示 |
| FR-102 | Event | 当新设备注册时，系统应自动生成该设备的统一命名空间实体（设备/部件/测点三级）并分配全局唯一 ID。 | Must | 注册后查询 |
| FR-103 | Ubiquitous | 系统应对每个测点维护元数据：量纲、采样率、量程、安装位置、校准日期、校准证书号。 | Must | 元数据完整性报告 |
| FR-104 | Event | 当采集数据到达时，系统应执行质量校验（缺失、超量程、冻结值、时间戳跳变），并给出 0–100 的数据质量分。 | Must | 注入脏数据验证 |
| FR-105 | Unwanted | 若某测点连续 5 分钟无数据，系统应将该测点标记为 `STALE` 并通知，但不得中断其他测点的处理。 | Must | 断流测试 |
| FR-106 | State | 当设备处于停机状态时，系统应自动切换至"停机基线"模式，暂停基于运行的阈值判定，避免误报。 | Must | 停机场景回放 |
| FR-107 | Ubiquitous | 系统应保留原始波形数据 ≥ 90 天，特征值 ≥ 3 年，事件与结论 ≥ 5 年。 | Must | 存储策略核查 |
| FR-108 | Option | 若启用边缘预处理，系统应支持在边缘完成重采样、滤波、特征提取，仅上传特征值与异常片段。 | Should | 带宽对比 |

### 3.2 模块 M2：状态检测与健康评估（SD/HA）

| ID | 类型 | 需求 | 优先级 | 验收方式 |
|---|---|---|---|---|
| FR-201 | Ubiquitous | 系统应对振动信号计算时域特征（RMS、峰值、峰峰值、峭度、偏度、裕度因子）与频域特征（FFT 主频、TOP5 谱峰、包络谱、边频带）。 | Must | 特征值对拍 |
| FR-202 | Event | 当振动烈度超过 ISO 20816 相应机型分区限值时，系统应生成对应等级的状态事件。 | Must | 标准案例验证 |
| FR-203 | Ubiquitous | 系统应输出 0–100 的健康指数 HI，并按绿（≥80）/黄（60–79）/橙（40–59）/红（<40）四级呈现。 | Must | 报告核对 |
| FR-204 | Ubiquitous | HI 的计算必须可解释：输出各特征对 HI 的贡献度（Shapley 或等价方法）。 | Must | 解释报告 |
| FR-205 | Event | 当检测到轴承特征频率（BPFO/BPFI/BSF/FTF）及其谐波时，系统应给出轴承类故障假设及置信度。 | Must | 已知故障回放 |
| FR-206 | Event | 当同一设备 24 小时内出现 ≥ 3 个不同维度的异常（振动/温度/电流）时，系统应触发"多源印证"标记，提升告警等级。 | Should | 场景构造 |
| FR-207 | Unwanted | 若某传感器通道失效，系统应降级使用剩余通道并输出"降级模式"标记与置信度下调说明，不得输出"正常"。 | Must | 通道拔除测试 |
| FR-208 | State | 当设备检修完成后，系统应支持"基线重置"，重新学习健康基线并记录重置原因与操作人。 | Must | 操作审计 |

### 3.3 模块 M3：预后与 RUL（PA）

| ID | 类型 | 需求 | 优先级 | 验收方式 |
|---|---|---|---|---|
| FR-301 | Ubiquitous | 系统应输出 RUL 的区间估计（P10/P50/P90），而非单点值。 | Must | 报告核对 |
| FR-302 | Ubiquitous | RUL 输出必须附带模型版本、训练数据时间窗、置信度与适用工况范围。 | Must | 报告核对 |
| FR-303 | Unwanted | 若设备运行工况超出模型训练分布（OOD），系统应标注"外推风险"并抑制精确数值，仅给趋势方向。 | Must | OOD 样本测试 |
| FR-304 | State | 当 RUL 中位数 < 30 天且趋势加速时，系统应自动升级为橙色并进入决策会诊流程。 | Must | 场景回放 |

### 3.4 模块 M4：交互入口（AG-解释层）

| ID | 类型 | 需求 | 优先级 | 验收方式 |
|---|---|---|---|---|
| FR-401 | Event | 当用户以自然语言提问设备状态时，系统应识别设备、时间窗、分析类型三要素，缺项时反问补齐。 | Must | 100 条测试集 |
| FR-402 | Ubiquitous | 系统应以 MCP 协议对外暴露诊断能力，工具清单见 docs/06 §3，工具总数 ≤ 12。 | Must | MCP 客户端联调 |
| FR-403 | Ubiquitous | 系统生成的每一条结论必须引用证据（测点 ID、时间窗、特征值、规则 ID 或模型版本），无证据的结论不得输出。 | Must | 抽样审计 |
| FR-404 | Unwanted | 若用户提问超出系统能力（如"预测明天产量"），系统应明确拒答并说明能力边界，不得编造。 | Must | 越界提问测试 |
| FR-405 | Ubiquitous | 系统应生成交互式 HTML 诊断报告，包含：结论、证据、频谱图、趋势图、建议动作、置信度。 | Must | 报告样例评审 |
| FR-406 | Event | 当用户对结论提出质疑时，系统应能展开"推理链"（用了哪些工具、看到什么数据、依据什么规则）。 | Should | 交互演示 |
| FR-407 | Option | 若启用语音入口，系统应支持语音提问并返回文字+语音摘要。 | Could | 演示 |

### 3.5 模块 M5：决策会诊（AG-执行层）

| ID | 类型 | 需求 | 优先级 | 验收方式 |
|---|---|---|---|---|
| FR-501 | Event | 当触发决策会诊时，系统应并行召集四个角色（车间/可靠性/生产/维修），各自基于授权数据独立输出意见。 | Must | 会诊日志 |
| FR-502 | Ubiquitous | 系统应设置独立评估者（Evaluator），对四角色意见做一致性校验与冲突识别，不得由生成方自评。 | Must | 冲突场景测试 |
| FR-503 | Ubiquitous | 会诊输出必须是"维护方案卡"，字段见 docs/06 §4.3，缺字段不得提交。 | Must | 卡片校验 |
| FR-504 | Ubiquitous | 方案卡必须包含经济性计算：停机成本、备件成本、延期风险成本、推荐窗口的净收益。 | Must | 财务复核 |
| FR-505 | Event | 当推荐窗口与生产排产冲突时，系统应给出 ≥ 2 个备选窗口及各自的代价对比。 | Must | 冲突场景 |
| FR-506 | Ubiquitous | 方案卡生成后必须经人工确认（设备科长/维修主管）方可转为工单。 | Must | 流程验证 |
| FR-507 | Event | 当人工确认后，系统应通过 EAM 接口创建工单草稿，并回写工单号至方案卡。 | Must | 联调 |
| FR-508 | Unwanted | 若 EAM 接口调用失败，系统应重试 3 次（指数退避）后转人工队列，并标记"未闭环"。 | Must | 故障注入 |
| FR-509 | State | 当方案卡被拒绝时，系统应记录拒绝原因分类（误报/时机不当/成本过高/其他），用于模型迭代。 | Must | 数据核查 |

### 3.6 模块 M6：告警与通知

| ID | 类型 | 需求 | 优先级 | 验收方式 |
|---|---|---|---|---|
| FR-601 | Ubiquitous | 系统应支持四级告警（绿/黄/橙/红），每级绑定明确的接收角色与响应时限。 | Must | 配置核查 |
| FR-602 | Event | 当橙色及以上告警在响应时限内未被"已知悉"时，系统应自动升级至上一级责任人。 | Must | 计时测试 |
| FR-603 | Ubiquitous | 系统应对同类告警设置抑制窗口（默认 4 小时），窗口内合并为一条并累加计数。 | Must | 场景测试 |
| FR-604 | Event | 当用户点击"已知悉"时，系统应要求选择处置动作（处理中/转工单/忽略并说明原因）。 | Must | 交互验证 |
| FR-605 | Ubiquitous | 每条告警必须携带"建议动作"，仅有分数的告警不得发送。 | Must | 消息模板核查 |

### 3.7 模块 M7：边缘与降级

| ID | 类型 | 需求 | 优先级 | 验收方式 |
|---|---|---|---|---|
| FR-701 | Unwanted | 若边缘与中心失联，边缘应继续本地诊断与告警，缓存结果并在恢复后补传。 | Must | 断网 30 分钟测试 |
| FR-702 | Unwanted | 若本地 LLM 不可用，系统应降级为"模板化报告 + 规则结论"，仍输出建议动作。 | Must | 服务停止测试 |
| FR-703 | Event | 当边缘缓存超过阈值（默认 20 GB）时，系统应按优先级淘汰（原始波形优先淘汰，结论永久保留）。 | Must | 容量测试 |
| FR-704 | Ubiquitous | 边缘节点应支持离线授权（License 有效期 ≥ 90 天），到期前 30 天告警。 | Should | 授权测试 |

### 3.8 模块 M8：审计与治理

| ID | 类型 | 需求 | 优先级 | 验收方式 |
|---|---|---|---|---|
| FR-801 | Ubiquitous | 系统应记录所有 Agent 工具调用（入参、出参、耗时、token、模型版本），保留 ≥ 1 年。 | Must | 日志核查 |
| FR-802 | Ubiquitous | 系统应支持按设备+时间窗回放一次完整诊断过程（数据→特征→规则→结论）。 | Must | 回放演示 |
| FR-803 | Event | 当检测到提示注入特征（指令覆盖、角色扮演、越权请求）时，系统应拦截并记录安全事件。 | Must | 红队 20 例 |
| FR-804 | Ubiquitous | 系统应提供模型/规则/提示词的版本管理与灰度切换能力，支持一键回滚。 | Must | 版本切换 |

## 4. 非功能需求（NFR）

|---|---|---|

|---|---|---|

| NFR-09 | 数据不丢失（断网） | 边缘缓存 ≥ 72 h |

### 4.3 安全

### 4.5 易用性

## 5. 数据需求

### 5.1 核心实体

| 实体 | 关键属性 | 说明 |
|---|---|---|
| Asset（设备） | asset_id, 名称, 型号, 位号, 装置, 关键度(A/B/C), 投运日期 | 统一命名空间根 |
| Component（部件） | comp_id, asset_id, 类型(轴承/齿轮/联轴器/叶轮), 位置 | 故障模式挂载点 |
| MeasurementPoint（测点） | mp_id, comp_id, 物理量(振动/温度/电流/转速), 方向(H/V/A), 采样率, 量程, 校准信息 | 数据最小单元 |
| Series（时序） | mp_id, ts, value, quality | TDengine 超级表 |
| Waveform（波形） | mp_id, ts_start, fs, samples(blob), trigger_reason | 原始波形，留厂 |
| FaultMode（故障模式） | fm_id, comp_type, 名称, 特征频率规则, 判据, 参考标准条款 | 知识库核心 |
| Evidence（证据） | ev_id, 类型, 引用对象, 时间窗, 数值 | 结论的依据 |
| Diagnosis（诊断） | diag_id, asset_id, 结论, 置信度, 证据链, 模型版本, 时间 | 一次诊断记录 |
| Recommendation（方案卡） | rec_id, diag_id, 窗口, 备件, 人力, 成本, 状态 | 决策输出 |
| Alert（告警） | alert_id, 等级, 规则, 责任人, 状态, 升级记录 | 通知 |
| AuditLog（审计） | actor, action, target, before/after, ts, trace_id | 合规 |

### 5.2 数据量估算（20 台设备）

| 数据类型 | 估算 |
|---|---|
| 特征值 | 20 台 × 20 测点 × 1/min × 86400 × 365 ≈ 2.1 亿点/年 |
| 原始波形 | 20 台 × 4 通道 × 25.6 kHz × 1 s × 24 次/天 ≈ 200 GB/年（压缩后） |
| 诊断记录 | ~5,000 条/年 |
| 方案卡 | ~600 张/年 |
