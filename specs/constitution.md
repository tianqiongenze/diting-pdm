# 项目宪法（Constitution）

> SDD（规范驱动开发）的最高约束文件。
> **任何 spec / plan / tasks / 代码，若与本宪法冲突，以本宪法为准。**
> 修改本文件需架构委员会 2/3 通过，并记录变更理由。

版本：v1.0 ｜ 生效：2026-10-21 ｜ 适用范围：Diting-PdM 全部模块

---

## 第一条 · 规格是唯一真相源

1.1 代码是规格的派生产物，不是相反。
1.2 任何功能开发前，必须存在对应的 `spec.md`；没有规格的代码一律不予合并。
1.3 规格变更必须先改文档、再改代码；"代码先行、文档补"视为违规。
1.4 规格必须机器可读、可验证：每条需求有 ID、有验收标准、有测试映射。

## 第二条 · 安全高于功能

2.1 系统**永不**向 PLC/DCS/SIS 下发控制指令。此条无例外，无"临时开启"。
2.2 任何写操作（工单、备件、排班）必须经人工确认，且确认令牌不可由模型生成。
2.3 权限判定在运行时层（Harness），不在提示词层。提示词中的"禁止"不构成控制。
2.4 数据源内容永远不被当作指令执行；所有外部文本必须置于数据隔离区。
2.5 发现安全缺陷时，功能开发立即暂停，直到缺陷关闭。

## 第三条 · 证据高于结论

3.1 任何诊断结论必须附带证据（测点、时间窗、特征值、规则/模型版本）。
3.2 无证据的结论不得输出，不得以"根据经验"替代。
3.3 每个结论必须可回放：给定 trace_id 能重建完整推理链。
3.4 置信度必须校准；未校准的置信度不得展示给用户。

## 第四条 · 降级优于崩溃

4.1 任一组件失效，系统必须降级而非整体不可用。
4.2 降级时必须显式标记（`degraded=true`），不得静默降级。
4.3 降级路径必须被测试覆盖，且每迭代至少执行一次混沌验证。
4.4 数据不足时，宁可说"数据不足"，不可说"正常"。

## 第五条 · 人机共决

5.1 关键决策（停机、更换、大额备件）必须留人工确认环节。
5.2 人工拒绝必须记录原因码，并回流至模型迭代。
5.3 系统输出"建议"，不输出"指令"；不替代法定检验与持证人员判断。
5.4 所有 AI 生成内容必须标识，并附免责声明。

## 第六条 · 可解释优先于精度

6.1 在精度提升与可解释性冲突时，优先可解释，除非精度差距 > 10 个百分点且有充分验证。
6.2 进入主链路的特征必须 ≤ 25 个，且每个有物理含义。
6.3 禁止"黑箱大模型直出结论"作为唯一路径；必须有规则/物理模型作为可解释兜底。

## 第七条 · 许可与合规不可妥协

7.1 生产环境禁止使用非商用许可的模型权重。
7.2 引入任何开源组件前，必须完成许可审查并登记。
7.3 代码许可与权重许可分别审查，不得混同。
7.4 L3/L4 级数据不得出厂区。

## 第八条 · 测试是交付的一部分

8.1 核心算法（特征、HI、RUL、权限、证据校验）必须 TDD。
8.2 每条功能需求至少对应 1 条 Gherkin 场景。
8.3 单元测试行覆盖率 ≥ 80%，核心算法 ≥ 90%。
8.4 "能跑"不是完成；"能回滚、能观测、能解释"才是完成（见 DoD）。

## 第九条 · 可替换性

9.1 算法、模型、协议适配、EAM 适配必须插件化，替换不改主干。
9.2 上层不得感知底层协议；统一命名空间是唯一入口。
9.3 任何组件替换的验证成本 ≤ 2 人日。

## 第十条 · 变更可追溯

10.1 判据、提示词、技能属于"受控资产"，变更需审批 + 灰度 + 可回滚。
10.2 每个架构决策必须有 ADR。
10.3 技术债必须登记，每迭代偿还至少 1 项。
10.4 提交信息必须能追溯到 spec ID 或 issue ID。

---

## 违规处理

| 违规类型 | 处理 |
|---|---|
| 违反第二条（安全） | 立即回滚 + 事件复盘 + 责任人通报 |
| 违反第一条（无规格开发） | PR 直接关闭 |
| 违反第七条（许可） | 停止发布 + 法务介入 |
| 其他 | 迭代回顾中讨论，登记技术债 |

---

## 附：本宪法的"为什么"

这十条不是流程洁癖，每一条都对应一个真实会发生的灾难：

- 第二条 ← 某厂因"AI 自动调整参数"导致批量废品
- 第三条 ← "AI 说轴承要坏" 但拿不出证据，维修班组集体抵制
- 第四条 ← 一个传感器掉线导致整条诊断链停摆三天
- 第五条 ← 自动建单造成备件错订，损失 40 万
- 第六条 ← 98% 准确率的黑箱模型无人敢用
- 第七条 ← LimiX-2 权重非商用，交付后被法务叫停
- 第八条 ← 上线演示完美，第一次断网全崩

**每一条都是用别人的学费换来的。**
